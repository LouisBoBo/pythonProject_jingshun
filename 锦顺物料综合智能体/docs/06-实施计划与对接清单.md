# 实施计划与对接清单

## 1. 分阶段计划

| 阶段 | 内容 | 产出 | 依赖 |
|------|------|------|------|
| **P0** | 登录 Tool + Token 会话变量 + 401 处理 | 可登录对话 | ERP 登录 API + 测试账号 |
| **P1** | search + inventory + 对话展示 | 只读领料能力 | 领料读接口 |
| **P2** | draft + submit + 确认卡片 + 查单状态 | 完整领料闭环 | 写接口 + 状态枚举 |
| **P3** | 主 Agent 上线 + 数据分析子工作流 Tool 化 | 综合助手 v1 | 拆分 `正式库.yml` |
| **P4** | SSO 预登录、混合任务优化、长期记忆 | 生产就绪 | 门户 / ERP 配合 |

### P0 验收标准

- 用户使用工号密码登录后，后续 HTTP Tool 带 Bearer 成功
- Token 过期返回友好提示，可重新登录
- 密码不出现在会话变量与日志中

### P1 验收标准

- 「查 XX 物料库存」返回 ERP 口径可用量
- 物料关键字检索返回列表，Agent 可让用户选型

### P2 验收标准

- 多轮补全数量、用途后可提交
- 提交前必须确认；重复确认不重复建单
- 「查单 GONxxx」返回正确状态

### P3 验收标准

- 原 9 条推荐数据分析问题结果与现网一致
- 同一对话内先统计再领料无上下文丢失

## 3. 安全与合规

| 项 | 要求 |
|----|------|
| 密码 | 不落库、不写 conversation 变量、不打印日志 |
| Token | 仅存会话变量；HTTPS 传输 |
| 权限 | 领料 API 服务端校验 `user.dept_id`；Agent 不能绕过 |
| 写操作 | 仅 ERP API；Text2SQL 账号 **只读** |
| 审计 | ERP 记录 `source=AI_ASSISTANT`；保留 Dify 对话与 Tool 日志 |
| 提交幂等 | `idempotency_key` 或 ERP 侧 draft 锁 |
| 敏感操作 | submit 必须用户明确确认，禁止 Agent 自动提交 |

## 4. 风险与缓解

| 风险 | 缓解 |
|------|------|
| ERP 接口未就绪 | P3 可先上线纯数据分析 Tool，领料 Tools  mock |
| 库存口径 SQL vs API 不一致 | 领料以 ERP API 为准；分析仍用 SQL，文案注明口径 |
| Agent 误提交 | 提示词铁律 + submit 仅响应「确认提交」+ 幂等 |
| 子工作流拆分回归 | 对比现网 10+ 固定用例自动化或人工回归 |
| Token 泄露 | 短过期时间 + HTTPS + 嵌入页 HttpOnly 传 token |

## 6. 测试用例摘要

### 登录

- 正确账密 → token 写入，可调用 inventory
- 错误密码 → 提示错误，无 token
- 过期 token → 401 → 引导重新登录

### 领料

- 单物料单数量 → 确认 → 提交成功返回 GON 号
- 库存不足 → 提示，不 silent submit
- 多轮改数量 → draft 更新，最终提交数量正确
- 重复「确认提交」→ 同一单号

### 数据分析（回归）

- 统计 2025 各月消耗（当年月上界）
- 追问「提供明细」→ 充分性判定触发重新取数
- 高精密事业部油墨库存（子类过滤）
- 外发物料默认排除

### 混合

- 查库存 + 够则领 → 一条对话完成
- 统计后「最多的那个帮我领」→ last_material 或 search
