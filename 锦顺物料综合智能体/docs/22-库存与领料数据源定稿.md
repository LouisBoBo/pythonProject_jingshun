## 1. 核心原则

| # | 原则 | 说明 |
|---|------|------|
| 1 | **物料相关数据 = 只能 DATA Fast** | 料号、名称、库存、统计、明细等 **全部** 走画布 **DATA Fast HTTP**（子 Chatflow Text2SQL），**禁止** ERP 自然语言搜料 HTTP、禁止 Agent 读类 Tool |
| 2 | **领料一次 Fast 查齐** | 进 Agent 前 **一次** DATA Fast：同时返回 **料号 + 名称 + 可用库存 + 单位**；**不再**单独 `erp_search_material` |
| 3 | **写 = Agent 只 3 个 erp_*** | `save_draft` / `submit` / `get`；料号从会话变量 `requisition_material_code` 填入 draft |
| 4 | **卡片数据 = DATA Fast 变量** | 确认卡片料号、库存均来自 Assigner 写入的会话变量 |
| 5 | **submit 不扣库存** | Mock：创单出 GON，不 `reserved_qty`、不 409 |
| 6 | **已废弃** | `query_material_data` Agent Tool；Agent/画布领料链 **不调用** `erp_search_material`、`erp_check_inventory` |

**一句话**：**所有物料读 = DATA Fast；Agent 只提交工单。**

---

## 2. 能力分层

```
┌──────────────────────────────────────────────────────────────┐
│  读（物料主数据、库存、统计、明细）                                │
│  画布 DATA Fast HTTP → 子 Chatflow → SQL Server 只读          │
│  · DATA 意图 → Fast → Answer                                  │
│  · 领料/MIXED → Agent 前同 Fast 链（料号+库存一次查齐）          │
└──────────────────────────────────────────────────────────────┘
                              │
                              ▼ requisition_material_code / available_qty …
┌──────────────────────────────────────────────────────────────┐
│  写（领料工单）                                                  │
│  Agent：save_draft →（确认）submit → get                      │
└──────────────────────────────────────────────────────────────┘
```

**为什么不用 ERP search HTTP**：自然语言走 ERP 检索不可靠；业务库 Text2SQL 是 **唯一** 物料数据口径，且查库存结果 **本身含料号**。

---

## 3. 领料标准链

```
用户：帮我领 10KG 阻焊油墨
  │
  ├─① DATA Fast（料号 + 名称 + 可用库存 + 单位）→ Assigner
  │
  ├─② Agent：erp_save_draft（material_code=会话变量）
  └─③ Final Answer：确认卡片

用户：确认提交
  └─ Agent：erp_submit_requisition → GON
```

## 5. 会话变量（领料 Fast 链 Assigner）

| 变量 | 说明 |
|------|------|
| `requisition_material_code` | DATA Fast 抽取的料号 |
| `requisition_material_name` | 物料名称 |
| `requisition_available_qty` | 可用库存 |
| `requisition_inventory_unit` | 单位 |
| `requisition_inventory_detail` | detail 全文（兜底） |
| `requisition_inventory_extract_ok` | `true` / `false` |

**不要**在本链写 `data_analysis_conversation_id`（避免覆盖纯查数追问）。

Code：[`build_requisition_inventory_query.py`](../workflows/code/build_requisition_inventory_query.py)、[`extract_requisition_material_from_detail.py`](../workflows/code/extract_requisition_material_from_detail.py)

## 6. 路由

| 用户说 | 路径 |
|--------|------|
| 统计 / 查库存 / 明细 | **DATA → Fast** |
| 帮我领 … | **DATA Fast（料号+库存）→ Agent draft** |
| 确认提交 / GON | **Agent**（确认提交跳过 Fast） |
