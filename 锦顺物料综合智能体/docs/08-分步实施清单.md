### 2.2 创建 erp_login

- [ ] **Tools → Create Custom Tool**（或导入 OpenAPI）
- [ ] 名称：`erp_login`

### 2.3 创建 erp_search_material

- [ ] GET，Query：`keyword`
- [ ] Header：`Authorization: Bearer {{access_token}}`（Tool 测试时手填 token；主应用阶段改 conversation 变量）
- [ ] 描述：按关键字或料号搜索物料，返回物料列表。

### 2.4 创建 erp_check_inventory

## 阶段 4：登录与会话变量

> **逐步操作**：[18-阶段4-登录与会话变量操作手册.md](18-阶段4-登录与会话变量操作手册.md)

### 4.1 方案选择（二选一）

**方案 A（推荐）：登录分支 + Variable Assigner**

```
User Input
  → If-Else（auth_token 为空？）
       true  → [本阶段可先用 LLM 提取工号密码] → HTTP Request(erp_login) → Code 解析 JSON → Variable Assigner → Agent
       false → Agent
  → Answer
```

**方案 B：ERP Session**

- ERP 用 `sys.conversation_id` 存 token，HTTP Tool 带 `X-Conversation-Id`
- Agent 仍负责触发 `erp_login`，但不写 Dify 变量

- [x] 选定方案并完成设计评审（**方案 A · 被动登录**）

### 4.2 实现方案 A（推荐步骤 · 被动登录）

## 常见问题速查

| 现象 | 排查 |
|------|------|
| Chatflow 无响应/卡住 | Celery 队列 `workflow_based_app_execution` |
| Agent 不调 Tool | 检查 Tool 描述、Instruction 是否点名 Tool 名；模型是否支持 FC |
| Tool 参数为空 | Start 是否定义 `question`；Publish as Tool 后是否重新添加到 Agent |
| 401 领料失败 | `auth_token` 是否写入；Header 是否引用 conversation 变量 |
| 追问不重新取数 | 问题在子 Chatflow 内，检查充分性判定节点，非主 Agent |
| Conversation 变量不更新 | 是否用 Variable Assigner；是否误用独立 Agent 应用 |
| submit 被误触发 | 加强 Instruction；或启用 Human Input |
