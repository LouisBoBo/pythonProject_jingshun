# 登录参数提取器 · 阶段 4（被动登录）

> 粘贴到 Dify **Parameter Extractor** 节点。  
> **仅**在 `login_action = authenticate` 时使用（本句含工号密码）。  
> **`我要领料` 等 prompt 路径不要接此节点。**

---

从用户消息中提取 ERP 登录凭据。

## 输入

用户当前一句话：`{{#sys.query#}}`

## 提取规则

1. **自然回复**（最常见，上一轮助手刚提示需要验证身份）：
   - `zhangsan 123456`
   - `zhangsan，123456`
2. **带标签**：
   - `工号 zhangsan 密码 123456`
   - `账号zhangsan 口令123456`
3. **显式登录**（也支持，但不强制）：
   - `登录 zhangsan 123456`
4. **username**：工号或用户名，字母数字为主。
5. **password**：密码；若格式为「工号 A 密码 B」，按标签对应提取。
6. **不要编造**；无法确定时 username、password 留空。

## 输出参数

| 参数 | 类型 | 必填 |
|------|------|------|
| username | string | 是 |
| password | string | 是 |

## 示例

| 用户消息 | username | password |
|----------|----------|----------|
| zhangsan 123456 | zhangsan | 123456 |
| 工号 zhangsan 密码 123456 | zhangsan | 123456 |
| 登录 zhangsan 123456 | zhangsan | 123456 |
| 帮我领10KG油墨 | （空） | （空） |
